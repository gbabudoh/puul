# PUUL Demo Guide

## 🎯 Demo Features

Your PUUL app now has a complete demo onboarding and login flow!

## 🚀 How to Use the Demo

### 1. Login Screen
- **Any credentials work!** Just enter any phone number and password
- Example: Phone: `1234567890`, Password: `demo`
- Click "Login" to proceed

### 2. Onboarding Flow
After login, you'll see a 4-page onboarding tutorial:
- **Page 1**: Welcome to PUUL
- **Page 2**: Category-Based Sharing
- **Page 3**: Control Your Privacy
- **Page 4**: PUUL Moments

**Navigation:**
- Swipe left/right to navigate
- Use "Next" button to go forward
- Use "Back" button to go backward
- Click "Skip" to jump to home screen
- Click "Get Started" on the last page

### 3. Home Screen
Shows 4 demo PUULs (categories):
- **Family** - 8 members, 2h ago
- **Work** - 12 members, 5h ago
- **Holiday 2024** - 5 members, 1d ago
- **Party Friends** - 15 members, 3d ago

**Features:**
- Tap any PUUL to see a "Coming soon" message
- Tap profile icon (top right) for profile
- Tap "New PUUL" button to create (coming soon)

The app is running in debug mode with hot reload enabled:
